REQUIREMENTS:

On CLI: The Python Script Requires The "aes_keys.txt" And "game.3ds"/"game.cci" To Be In The Same Folder/Directory As The Script.

On GUI: The Python Script Lets You Select Where The "aes_keys.txt" And "game.3ds"/"game.cci" Are


The Python Script Requires The Python Library, "python3-pycryptodome", Which Can Be Installed On Debian/Ubuntu Based Distributions With This Command:  "sudo apt install python3-pycryptodome"
